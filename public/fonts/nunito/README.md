# Nunito web fonts

Self-hosted Nunito static normal weights 200, 300, 400, 600, 700, 800 and 900.
WOFF2 is preferred; WOFF is retained as a fallback.

Source webfont package: `@bu0nq/webfont.nunito` 0.2.0.

The font software is licensed under the SIL Open Font License 1.1; see `OFL.txt`.
The supplied npm package's MIT license applies to its package code and is retained
separately as `PACKAGE-LICENSE-MIT.txt`.

The supplied webfont subset covers Latin/Cyrillic characters; Arabic/Persian glyphs
fall through to the page sans-serif fallback.
